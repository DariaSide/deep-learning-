# Лабораторная работа 2

Тема: распознавание именованных сущностей (NER) с дообучением предобученного энкодера.

## Содержание

* `hw2_nlp.ipynb`: полностью выполненный notebook с сохраненными результатами
* `requirements.txt`: зафиксированные зависимости из задания
* `assignment.txt`: исходные инструкции к работе
* `artifacts/metrics.json`: итоговые метрики, параметры запуска, абляция и бонусы
* `artifacts/manual_ner_60.jsonl`: 60 дополнительно размеченных предложений для бонуса 6.1

## Эксперимент

* модель: `cointegrated/rubert-tiny2`, ревизия `e8ed3b0c8bbf4fb6984c3de043bf7d2f4e5969ae`
* датасет: русская часть WikiNEuRal, 15 000 train примеров, 9 232 validation и 11 580 test
* устройство: Apple Silicon (MPS)
* финальный режим: `FAST_MODE = False`, 3 эпохи
* бонусы: 6.1, 6.3, 6.4 и 6.5, суммарно с ограничением до 4 дополнительных баллов

## Результаты

* словарный baseline: entity micro F1 `0.5220`
* случайная голова: entity micro F1 `0.0346`
* дообученная модель на test: entity micro F1 `0.8101`
* полное дообучение на validation: entity micro F1 `0.8208`
* заморозка энкодера на validation: entity micro F1 `0.5271`
* дополнительное обучение на ручной разметке: F1 вырос с `0.4615` до `1.0000` на отдельном наборе из 15 примеров
* лучший порог уверенности: validation micro F1 `0.8318` при пороге `0.70`
* `torch.compile`: предсказания совпали, измеренное ускорение `14.87x` на MPS

Notebook прошел полный Restart and Run All. Все обязательные разделы и четыре бонусных задания содержат сохраненные результаты.
